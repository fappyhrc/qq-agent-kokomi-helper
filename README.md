# 战舰世界助手（kokomi）· 使用手册

> 群里发 `@机器人 kokomi me`，机器人把 Kokomi 服务渲染好的战绩图发出来。
> 与另一个插件「战舰世界助手（yuyuko）」是**两个独立数据源**，可以同时开着、互不干扰。

- 触发词：**`kokomi`**（yuyuko 插件是 `yuyuko`）
- 图片服务端口：**32802**（yuyuko 插件是 32801）
- **本插件是纯 Node 实现**：不需要 Python、不需要常驻进程、不需要下载依赖

---

## 1. 安装

**只有一步**：把 `kokomi-helper` 整个文件夹放进 QQ Agent 的 `plugins` 目录：

```
<QQ Agent 安装目录>\plugins\kokomi-helper\
```

然后在 QQ Agent →「插件」页找到 **战舰世界助手（kokomi）**，打开开关。
（本插件出于安全考虑**默认关闭**。）

没有 Python、没有依赖安装、没有需要保持开着的窗口。

### 默认配置

出厂就已经指向一个可用的 Kokomi 服务，所以**装好即可用**：

| 设置项 | 默认值 |
|---|---|
| Kokomi 服务地址 | `http://43.133.59.53:8000/bot/` |
| 访问口令 | `user` |

> ⚠️ 这是一个**第三方 IP 直连服务**（没有域名）。如果它哪天不可用了，
> 查询会给出明确提示，你可以换成自己的服务地址（见下）。

## 2. 在群里怎么用

### 2.1 基本用法

```
@机器人 kokomi help      ← 先看帮助图
@机器人 kokomi link asia 你的游戏昵称    ← 绑定账号
@机器人 kokomi me        ← 查自己的总水表
```

两个条件缺一不可：**@ 了机器人本人** + **`kokomi` 是去掉 @ 之后的第一个词**。
`kokomi` 后面的内容会交给 Kokomi 服务。

### 2.2 可以用大白话，不必背指令表

`kokomi` 后面**不要求写成标准指令**。你可以直接说人话，AI 会翻成正确指令再查：

| 你可以这样说 | AI 实际执行的查询 |
|---|---|
| `kokomi 帮我看看我最近的战绩` | `me recent 7` |
| `kokomi 小鲸鱼最近打得怎么样` | `me recent 7`（查自己时是 `me`） |
| `kokomi 查一下欧服的 TestNotExist` | `me eu TestNotExist` |
| `kokomi 我这周开工了没` | `me recent 7` |
| `kokomi 大和这条船我打得怎么样` | `me ship 大和` |

**但它不会替你编参数**：服务器、昵称、船名这些必须是你自己说的。
缺了关键信息（比如"查一下某人"却没说是哪个服），它会先反问你一句，而不是随便猜一个。

听不懂的写法它会**如实说查不了**，并建议你发 `kokomi help` 看帮助图——不会硬凑一个结果。

### 2.3 没绑定时会怎样

服务会回一句文字：

```
请先绑定游戏账号，发送'wws help'可查询帮助文档
```

注意那句里的 `wws` 是**服务端自己的写法**——在本插件里要换成 `kokomi`
（即发 `@机器人 kokomi help`）。绑定后 `kokomi me` 才会出图。

### 2.4 常用指令（想写标准写法时参考）

| 群里发送 | 作用 |
|---|---|
| `kokomi help` | 帮助图（**最全的指令表就在这张图里**） |
| `kokomi bind <服务器> <昵称>` | 绑定账号 |
| `kokomi me bind` | 查看当前绑定 |
| `kokomi me` | 自己的总体水表 |
| `kokomi me info` | 详细水表 |
| `kokomi me recent 7` | 近期战绩（也可 `recent 30`） |
| `kokomi me ship 大和` | 单船战绩 |
| `kokomi me oper` / `me cw` / `me rank` | 行动 / 军团战 / 排位 |
| `kokomi me clan` | 公会信息 |
| `kokomi me <服务器> <昵称>` | 查别人（如 `me asia TestNotExist`） |
| `kokomi me online` | 服务器在线人数 |
| `kokomi me lang cn/en/ja` | 切换出图语言 |
| `kokomi me pr hide/pr` | 关闭/开启评分显示 |

> 服务器取值：`asia` / `eu` / `na` / `ru` / `cn`。
> 完整指令表以 `kokomi help` 那张图为准（各服务端版本可能略有差异）。

### 2.5 和 yuyuko 插件一起用

```
@机器人 yuyuko me      ← yuyuko 数据源
@机器人 kokomi me      ← Kokomi 数据源
```

**两个不同来源，数字可能不同**，不要混在一起比较或相加。

## 3. 设置项

| 设置项 | 默认 | 说明 |
|---|---|---|
| **Kokomi 服务地址** | `http://43.133.59.53:8000/bot/` | 服务入口；它接收指令并**在服务端渲染好图片**，把图片地址返回 |
| **访问口令** | `user` | 作为**查询参数** `?token=` 传给服务（不是请求头） |
| 查询超时 | 60000 ms | 等待服务返回结果（含服务端渲染） |
| 图片下载超时 | 60000 ms | 图片在**另一个主机**上，这里是下载那张图的超时 |
| 把渲染图直接发到群里 | 开 | 关闭后由模型决定是否发图 |
| 把文字结果注入上下文 | 开 | 例如未绑定时那句提示会交给模型 |
| 上报平台标识 | `qq_bot` | 服务端按 `platform + user_id` 记录绑定，换值会读不到原绑定 |
| 发给服务的指令前缀 | `wws` | 服务端认的触发词；插件把 `kokomi me` 转成 `wws me` 发出，一般不用改 |
| 本地图片服务 | 开 | 端口 32802；端口被占用时自动退回文件/base64 |
| 战绩图体积上限 | 12 MB | 超过则拒绝发送并提示 |
| 发图时 @ 触发者 / 引用触发消息 | 关 / 关 | 减少群里刷屏 |

修改设置**无需重启**：配置每次查询时现读。

**换自己的服务**：把「Kokomi 服务地址」改成你的实例地址（形状要一样：接收 `message` 参数并返回
`{"type":"img","img":"<图片地址>"}` 或 `{"type":"msg","msg":"..."}`）。上游
[`Kokomi_Bot`](https://github.com/SangonomiyaKoko/Kokomi_Bot) 与
[`Kokomi_Backend`](https://github.com/SangonomiyaKoko/Kokomi_Backend) 可自建。

## 4. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 发指令完全没反应 | 插件是否已启用？是否 **@ 了机器人**？`kokomi` 是否在**最前面**？ |
| 提示「Token 不可用」 | 「访问口令」不对。默认 `user` |
| 提示「连不上服务」 | 服务地址写错，或该服务当前不可用（可以换自己的） |
| 提示「查询超时」 | 服务端渲染慢或网络差；可调大「查询超时」 |
| 回一句"请先绑定游戏账号…" | 正常：先 `kokomi link <服务器> <昵称>`（提示里的 `wws` 换成 `kokomi`） |
| 回了"输入的指令或参数有误" | 该指令服务端不认，或参数不对；先发 `kokomi help` 看帮助图 |
| 只有文字没有图 | 服务返回的就是文字（例如业务错误），不是插件问题 |
| 群里聊到 kokomi 也被抢话 | 不该发生（要求 @ 机器人）；检查「必须 @ 机器人」是否被关掉 |

排障先开「调试日志」开关（口令不会写进日志）。

---

## 5. 已知限制

- **依赖第三方服务**：默认地址是一个 IP 直连的第三方服务，**没有域名、没有 SLA**。
  它长期不可用时请换自己的实例。
- **图片样式由服务端决定**：插件只负责把图取回来发出去，不控制排版
- **服务端才认绑定**：绑定关系存在服务上，换服务地址后需要重新绑定
- **需要能访问该服务**：若你的网络环境访问不到，插件会给出"连不上服务"的提示
